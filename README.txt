A LITTLE CHAPTER OF US — WEBSITE STARTER

Isi folder:
- index.html: struktur halaman
- style.css: warna, layout, dan animasi
- script.js: navigasi dan interaksi
- assets/images/: tempat foto pribadi
- assets/music/: tempat file musik

CARA MEMBUKA:
1. Ekstrak ZIP.
2. Buka folder `a-little-chapter-of-us` di VS Code.
3. Buka `index.html` di browser. Untuk workflow yang nyaman, kamu bisa pakai ekstensi Live Server.
4. Klik "open our little world" untuk mulai menjelajahi website.

CARA PERSONALISASI:
- Ubah teks langsung di `index.html`.
- Ubah warna di bagian `:root` pada `style.css`.
- Untuk lagu spesial, letakkan file audio yang kamu punya izin untuk gunakan di `assets/music/song.mp3`.
- Untuk musik latar, letakkan file audio berbeda di `assets/music/background.mp3`.
  Kedua file audio tidak disertakan; player disiapkan sebagai template.
- Untuk foto, tambahkan foto di `assets/images/`, lalu kita bisa mengubah placeholder foto di HTML agar memakai nama file tersebut.
- Ganti contoh timeline, isi kartu Hall of Fame, alasan memilih lagu, dan surat dengan kenangan kalian sendiri.

CATATAN:
- Font Google Fonts memerlukan koneksi internet.
- Audio tidak diputar otomatis; pengunjung perlu menekan tombol play.
- Pastikan kamu punya izin untuk membagikan foto dan musik yang digunakan.
